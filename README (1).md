# Healthcare Dataset Analysis

Midterm assessment project — data cleaning, SQL-based analysis, and visualization of a healthcare patient dataset using Python (Pandas), SQLite, and Matplotlib.

## Overview

This project takes a raw healthcare patient dataset (`healthcare_dataset.csv`) and:
1. Loads and stores it in both Excel and a SQLite database
2. Cleans it (duplicates, inconsistent capitalization, whitespace issues, invalid numeric values)
3. Runs SQL queries to analyze patients by medical condition, age, billing, gender, blood type, insurance provider, admission type, test results, and medication
4. Visualizes each of these breakdowns with Matplotlib charts

## How to Run

1. Place `healthcare_dataset.csv` in the same folder as `Code.ipynb`.
2. Open the notebook (Jupyter Notebook / JupyterLab / VS Code).
3. Run all cells in order, top to bottom.
4. Outputs generated:
   - `healthcare_dataset.xlsx` — raw data as Excel
   - `healthcare_db.db` — SQLite database with the `patient_rawData` table
   - `healthcare_dataset_cleaned.xlsx` — cleaned dataset
   - All charts rendered inline in the notebook

## Workflow

### 1. Load & Store
- CSV loaded into a Pandas DataFrame
- Exported to Excel
- Loaded into a SQLite table (`patient_rawData`) for SQL-based analysis

### 2. Data Cleaning
- **Duplicates:** checked and removed both in Pandas and via a SQL `DELETE` using `rowid`/`MIN(rowid)` grouping
- **Text formatting:** standardized name capitalization (`str.title()`), checked for mixed-case values and stray/multiple whitespace across all text columns
- **Dates:** parsed `Discharge Date` to datetime and checked for invalid sequences (discharge before admission)
- **Numeric validation:** checked `Age`, `Billing Amount`, and `Room Number` for out-of-range or negative values; rows with negative billing amounts (data entry errors) were removed
- **Missing values:** checked every column for null or empty/whitespace-only values

### 3. SQL Analysis
Queries grouped by **Medical Condition** to compute:
- Patient count, average/min/max age
- Average/min/max billing amount
- Gender distribution (%)
- Blood type distribution (%)
- Insurance provider distribution (%)
- Admission type distribution (%)
- Abnormal test result rate (%)
- Medication frequency
- Age-group breakdown (0–19, 20–39, 40–59, 60–79, 80–99, 100–119)

### 4. Visualization
Each SQL result is visualized with Matplotlib:
- Bar charts — average age, average billing, patient count, abnormal test rate by condition
- Nested donut / subplot pies — gender distribution by condition
- Heatmap — medication frequency by condition
- Stacked bar chart — age group distribution by condition
- Boxplot — outlier check on Age, Billing Amount, Room Number

## Dashboard PDF

`Healthcare_Data_Analysis_Dashboard.pdf` compiles all 9 charts generated in the notebook into a single report with section headings and short interpretations, useful for sharing results without needing to open the notebook.

## Notes

- The dataset used contains 6 medical conditions: Arthritis, Asthma, Cancer, Diabetes, Hypertension, and Obesity.
- Gender distribution is close to even (~50/50) across every condition in this dataset.
- Negative billing values were treated as data-entry errors and dropped rather than corrected, since there was no reliable way to recover the true amount.
